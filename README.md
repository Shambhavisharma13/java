# ☕ Java Programming Practice

A collection of **Java programming concepts and practice programs** created while learning and strengthening core Java skills.

This repository focuses on building a strong foundation in **Java, Object-Oriented Programming, Exception Handling, Multithreading, Arrays, and Recursion**.

## 📚 Topics Covered

### 🔹 Arrays

Practice programs based on Java arrays, including basic operations and array manipulation.

### 🔹 Object-Oriented Programming (OOP)

The repository contains multiple programs covering important OOP concepts:

* Classes and Objects
* Constructors
* Encapsulation
* Inheritance
* Polymorphism
* Abstraction
* Method Overloading
* Method Overriding
* Interfaces

### 🔹 Exception Handling

Programs demonstrating Java exception-handling concepts:

* `try`
* `catch`
* `finally`
* `throw`
* `throws`
* Custom exceptions

### 🔹 Multithreading

Practice programs related to Java threads and concurrent execution.

Topics include:

* Thread creation
* Thread lifecycle
* `Thread` class
* `Runnable`
* Multiple threads
* Thread execution

### 🔹 Recursion

Basic recursion programs to understand how a method calls itself and how recursive problems can be solved.

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Shambhavisharma13/java.git
```

### 2. Open the project

Open the project folder in **VS Code** or **IntelliJ IDEA**.

### 3. Compile a Java program

For example:

```bash
javac Array.java
```

### 4. Run the program

```bash
java Array
```

You can similarly compile and run the other Java files.
